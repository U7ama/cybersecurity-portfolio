# Hashim Aslam - Cybersecurity Portfolio

## About Me

I'm a BS Software Engineering student at COMSATS University Islamabad, Lahore Campus, working toward a long-term specialization in cybersecurity. Alongside my degree, I'm building practical skills through structured self-study, including Google's Cybersecurity Professional Certificate and Princeton's Algorithms and Data Structures course.

I hold two leadership roles in my department, Class Representative and Batch Ambassador, which have sharpened my communication and organizational skills. I've also built several full-stack projects, including an e-commerce platform (React.js, FastAPI, MongoDB), a password manager (PostgreSQL), and a Java/JavaFX task and team management system, giving me a solid foundation in how software is designed and where it can be attacked.

My goal is to move into a cybersecurity role where I can combine this development background with security-focused skills such as network analysis, vulnerability assessment, and incident response. This repository documents that learning journey.
